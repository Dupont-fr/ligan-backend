# Authentification — Ligan+

Sprint 1 — *en cours de planification*.

Fonctionnalités prévues :

- Register avec **vérification par email** envoyée automatiquement à la création du compte
  (accès bloqué tant que non vérifié) ;
- Login / Logout ;
- JWT + refresh token ;
- Mot de passe oublié / réinitialisation ;
- Rôles : `CUSTOMER`, `PROFESSIONAL`, `ADMIN` ;
- Middlewares `requireAuth`, `requireRole(...)` ;
- Emails transactionnels au nom de **Ligan+** avec un rendu responsive.

Détails implémentés ajoutés à la fin du Sprint 1.
